当サイトが毎週集計している、ヤフオク!の実落札データにもとづく中央値です。同じ銘柄でも年数で水準がまったく異なることが分かります。

2. 手元のボトルが何年ものかの見分け方

  1. 正面ラベル中央〜下部の数字を見る — 「12」「15」「18」「21」「30」などの数字＋「YEARS OLD」が入っています
  2. 化粧箱・筒缶を確認する — ラベルが読めない場合も、箱側に年数が印字されていることが多いです
  3. 裏ラベル・肩ラベルも見る — 正面が摩耗していても、裏や肩に年数・度数が残っている場合があります
  4. 年数がどこにも無ければノンエイジ — IPAカスク等の実験的シリーズの可能性があります（後述）
  5. それでも不明なら写真を添えて査定へ — 正面・裏・キャップ・液面の写真を用意し、専門知識のある業者に判定してもらうのが確実です

3. 年数表記のないボトルについて

グレンフィディックには、熟成年数を表記しないシリーズもあります。代表的なものが「IPAカスク・フィニッシュ」「プロジェクトXX」「ファイア＆ケイン」などの実験的リリースです。

ただし、これらは定番3本（12年・15年・18年）に比べて流通量が少なく、当サイトの集計基準（過去180日の実落札・n≥20件）を満たすデータが集まっていません。そのため、本ページではこれらの中央値を数値として掲載していません。推定値で埋めることはせず、データが集まり次第、他の年代と同じ基準で追加します。

年数表記のないボトルをお持ちの場合は、ウイスキーの「年代指定なし(NV)」とは もあわせてご覧ください。

4. 箱なし・開封済みの扱い

業界一般の目安として、状態による減額幅はおおむね次のとおりです（業者により基準は異なります）。

状態市場相場に対する目安12年の場合の目安額
未開封・箱あり（完品）100%2,858円
未開封・箱なし（ラベル良好）80〜90%程度約2,286〜2,572円
開封済み・残量9割以上30〜40%程度約857〜1,143円

※上記は市場相場（ヤフオク中央値）に業界一般の減額率を掛けた目安であり、特定業者の買取価格ではありません。実際の査定額は必ず複数社でご確認ください。

5. グレンフィディックを高く売る5つのコツ

  1. 化粧箱・冊子など付属品を揃える — 完品と箱なしで1〜2割の差が出ます
  2. 未開封のまま売る — 開封済みは大幅減額の傾向です
  3. 年数を正確に伝える — 12年と18年の取り違えは査定額に直結します
  4. 複数業者で相見積もりを取る — 18年以上は在庫状況で査定額が動きやすく、差が出ます
  5. 保管状態を整える — 直射日光を避け、縦置き・温度変化の少ない場所で保管。液面低下・ラベル褪色は減額要因です

6. 無料査定の使い方

12年など流通量の多いボトルは相場が安定している一方、18年・30年は業者ごとの在庫状況で査定額が変わります。一括査定で相場感を掴んでから、専門店の個別査定と比較するのが効率的です。

7. よくある質問

グレンフィディックの買取相場はいくらですか？
年数によって大きく異なります。当サイト集計（ヤフオク過去180日の実落札・IQR外れ値除去後の中央値・取得日 2026-08-24）では、12年2,858円、15年5,060円、18年10,500円、30年66,000円です。同じ「グレンフィディック」でも12年と30年では20倍以上の開きがあるため、まず手元のボトルの年数を確定させてください。
手元のグレンフィディックが何年ものか分かりません。どこを見ればいいですか？
三角形のボトル正面ラベルの中央〜下部に「12」「15」「18」「21」「30」などの数字と「YEARS OLD」の表記があります。数字が読み取れない場合は、化粧箱・裏ラベル・肩ラベルにも年数が入っていることが多いので確認してください。それでも判別できない場合は、正面・裏・キャップ・液面の写真を用意して買取業者に判定してもらうのが確実です。
グレンフィディックに年数表記のないボトルはありますか？
あります。「IPAカスク・フィニッシュ」「プロジェクトXX」「ファイア＆ケイン」などの実験的シリーズは熟成年数を表記していません。ただしこれらは流通量が少なく、当サイトで実落札データを十分な件数（n≥20）集められていないため、本ページでは中央値の数値を掲載していません。データが集まり次第、掲載します。
箱なし・開封済みでも買取してもらえますか？
はい、可能です。業界一般の目安として、未開封・箱なし（ラベル良好）で市場相場の80〜90%程度、開封済みで残量9割以上なら30〜40%程度が目安です（業者により評価基準は異なります）。化粧箱や冊子が部分的に残っている場合は一緒に査定に出すと評価されます。
グレンフィディックを高く売るコツは？
(1)化粧箱・冊子など付属品を揃える、(2)未開封のまま売る、(3)年数を正確に伝える（12年と18年の取り違えは査定額に直結します）、(4)複数業者で相見積もりを取る、(5)直射日光を避け縦置きで保管する、の5つが基本です。12年など流通量の多いボトルは業者間の差が出にくい一方、18年以上は在庫状況で査定額が動きやすくなります。
