1. ラベル別の落札価格

ラベルごとにヤフオクの落札済みオークションを検索し、出品タイトルを1件ずつ確認しました。 ブルーラベルは750mlの通常品だけを残し、1Lボトル、干支などの限定デザイン、オールデスト、キングジョージ5世、カスクエディションは除いています。 ブラックラベルはダブルブラック・シェリーエディション・地域限定品（スペイサイド オリジン等）と旧ボトルを除きました。 いずれもセット・ミニボトルを除き、IQR（四分位範囲の1.5倍）で外れ値を除いた中央値です。件数（n）が20件未満の区分は中央値を掲載していません。

2. ジョニーウォーカーとは（公式情報）

  • はじまり: 日本公式サイトによると、1820年にジョン・ウォーカーがスコットランドのキルマーノックで食料品店を開き、シングルモルトをブレンドして品質の安定したウイスキーを売り出したのが始まりです。1857年に亡くなった後、事業は息子のアレクサンダーが継ぎました。
  • ブラックラベル 12年: スコットランド各地の、樽で12年以上熟成させたシングルモルトとグレーンウイスキーのみを使うと説明されています。日本公式サイトの表記は700ml・40%です。
  • ブルーラベル: 長く閉鎖された蒸溜所の原酒を含め、1万樽のうちわずか1樽を厳選すると説明されています。表記は750ml・40%です。

※ジョニーウォーカー日本公式サイトの各ページより（2026-11-12確認）。ゴールドラベル リザーブは日本公式サイトの定番品一覧に掲載がないため、ヤフオクの出品表記（700ml・40%）で記載しています。

3. 売る前の確認事項

  • ラベルの色と容量を確認する: ブルーラベルは750mlと1Lで価格帯が異なります。限定デザインは通常品と別に査定されます。
  • ブルーラベルは付属品をそろえる: ヤフオクでは箱付きの出品が多くありました（付属品の有無による価格差は集計していません）。
  • ブラックラベルはまとめて出す: 1本あたり1,000〜2,000円台の水準のため、ほかのお酒と一緒に査定に出すと手間が減ります。
  • 相見積もり: 業者ごとに販売先と在庫が異なるため、複数の業者で比べてください。手順はウイスキーを高く売るコツにまとめています。

4. よくある質問

ジョニーウォーカーの買取相場はいくらですか？
当サイトの集計では、ヤフオクの落札価格の中央値はブルーラベル（750ml）が16,013円（n=80件）、ブラックラベル12年（700ml）が1,648円（n=27件）です（取得日 2026-11-12）。落札された市場価格であり、業者の買取額はここから手数料等を引いた水準になります。
ブルーラベルが高いのはなぜですか？
日本公式サイトは、ブルーラベルについて「1万樽のうちわずか1樽を厳選」し、長く閉鎖された蒸溜所の原酒も含むと説明しています。ラベルの色ごとに価格帯は大きく異なり、当サイトの集計でもブルーラベルの中央値はブラックラベル12年の約10倍でした。
限定デザインのブルーラベルや1Lボトルはいくらですか？
干支デザイン・キングジョージ5世・1Lボトルなどは、通常の750mlと価格帯が異なるため今回の集計から除いています。件数が少なく中央値は出していません。複数の業者に個別の査定を依頼してください。
ジョニーウォーカー18年はいくらですか？
ヤフオクの「18年」は、プラチナラベル・アルティメット・ゴールドラベル18年など名称の異なるボトルが混在しています。1つの中央値にまとめると誤解を招くため、当サイトでは集計していません。

  • ヤフオク 落札済みオークション検索（取得日 2026-11-12）。検索語「ジョニーウォーカー ブルーラベル」「ジョニーウォーカー ブラックラベル 12年」「ジョニーウォーカー ゴールドラベル」。タイトルを目視で確認し、IQR外れ値除去後の中央値を算出。n<20の区分は中央値を出しません。詳しくは集計方法をご覧ください。
