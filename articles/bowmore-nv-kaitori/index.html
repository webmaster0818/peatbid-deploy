1. 年代指定なしのボウモアに該当するボトル

ラベルに「12年」「18年」などの熟成年数表記がないボウモアは、「ボウモア No.1（ナンバーワン）」である可能性が最も高いと考えられます。No.1は現行ラインナップのエントリーにあたるノンエイジ（NV）ボトルで、ファーストフィル・バーボン樽で熟成した原酒を主体としています。

そのほか、年数表記のないボウモアには、過去に流通した「スモールバッチ」や1990年代〜2000年代のエントリーボトル「レジェンド」、免税店（トラベルリテール）向けの「ゴールドリーフ」「ブラックロック」などがあります。オークションや買取店ではこれらをまとめて「ボウモア 年代指定なし」「ボウモア NV（ノンヴィンテージ）」と表記することがあります。

2. 年数表記のないボウモアの主なボトルライン

ボウモアは1779年創業、アイラ島最古とされる蒸溜所です。潮の香りと穏やかなスモーキーさのバランスで知られ、年数表記のあるボトル（12年・15年・18年・25年など）に加えて、以下のようなノンエイジ（NV）ボトルを展開してきました。

同じ「年代指定なし」でも、どのボトルラインかによって市場での評価は異なります。特に旧流通品（スモールバッチ・レジェンド）や免税店限定品は現在入手しにくいため、状態が良ければ評価が乗る場合があります。査定に出す前に、ボトル名をご確認ください。

なお、超高額で知られるブラックボウモアはヴィンテージ（蒸溜年）表記のある別格のコレクターズボトルで、本ページのNVボトルとは全く異なる価格帯です。

4. 手元のボトルの見分け方

「実家から出てきたボウモア、年代がわからない」という場合は、以下の順で確認すると特定できます。

  1. ラベル正面の数字を確認 — 「12」「15」「18」「25」などの数字（YEARS OLD表記）があれば、年代付きのボトルです。数字がなければNVボトルです
  2. ボトル名の表記を確認 — 「No.1」「SMALL BATCH」「LEGEND」「GOLD REEF」「BLACK ROCK」などの名称がラベルに記載されています。この名称がそのままボトルラインの特定材料になります
  3. キャップ・封緘の状態 — 未開封かどうかで査定は大きく変わります。キャップシールの破れ・緩みがないかご確認ください
  4. ボトル形状・ラベルデザイン — 旧流通品（レジェンド等）は現行品とラベルデザインが異なります。デザインが古い場合は流通時期のヒントになります
  5. 裏ラベル・輸入シール — 正規輸入品には日本語の輸入者表示シールが貼られています。並行輸入品・免税店購入品はこれがない場合があり、その旨を業者に伝えると査定がスムーズです

どうしても特定できない場合は、無理に判断せずボトル全体・ラベル正面・裏ラベルの写真を撮って査定に出すのが確実です。お酒の買取専門店では、写真からボトルの種類を特定できる場合があります。

5. 年代指定なしのボウモアを高く売る5つのコツ

  1. 外箱・カートンを揃える — 付属品の有無で査定額が変動します。箱がなくても売却は可能ですが、あれば必ず一緒に
  2. 未開封のまま売る — 開封済みは大幅な減額となります。売却を予定している場合は開栓しないことをおすすめします
  3. ボトル名を正確に伝える — 「ボウモアの年代なし」ではなく「ボウモア No.1」「スモールバッチ」と特定して伝えると、旧流通品・限定品の評価漏れを防げます
  4. 複数業者で相見積もり — 同じボトルでも業者により査定額が10〜20%異なることがあります。3社以上で比較することをおすすめします
  5. 適切な保管環境を保つ — 直射日光を避け、縦置きで保管してください。液面低下・ラベル褪色は減額要因です

6. よくある質問

年代表記のないボウモアはどのボトルですか？
現行では「ボウモア No.1」（ファーストフィル・バーボン樽原酒主体のノンエイジ）が代表です。ほかに過去に流通した「スモールバッチ」「レジェンド」、免税店（トラベルリテール）向けの「ゴールドリーフ」「ブラックロック」などが年数表記のないボトルに該当します。ラベル正面に「12」「18」「25」などの数字がなければ、これらのいずれかであると考えられます。
年代指定なしのボウモアでも買取してもらえますか？相場はいくらですか？
はい、買取可能です。年代指定なし（NV）ボウモアの実勢中央値は現在集計中です（毎週更新のため、近日掲載予定）。参考として、年代付きのボウモア18年は実勢中央値10,999円、25年は66,000円（2026-10-26時点・ヤフオク落札中央値）で、現行NVボトルは一般にこれより手頃な価格帯で取引されます。実際の査定額は業者・状態により変動するため、複数社での相見積もりをおすすめします。
年代指定なしのボウモアを高く売るコツは？
(1)外箱・カートン等の付属品を揃える、(2)未開封のまま売る、(3)ボトル名（No.1／スモールバッチ等）を正確に業者へ伝える、(4)複数業者で相見積もりを取る、(5)直射日光を避け縦置きで保管する、の5つが基本です。終売・旧流通ボトル（スモールバッチ・レジェンド等）は現行品より評価が乗る場合があるため、ボトル名の特定が特に重要です。
